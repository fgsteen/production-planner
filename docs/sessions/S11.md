## Decisions
- v1 is kept: tag `v1-yearly`, copied to `v2/`, v2 at the Pages root and v1 at `/v1/` (R70, ADR 0013).
- One factory with a 1-shift step. The window is 9 shifts and is checked with expected usage. Shift 1 is frozen (R71, R76, R77, R80).
- Replanning: earliest breach first, fix just enough to reach min. Below min: add > move > swap. Above max: move later > swap > cancel (R81–R83).
- Kept: rate × OEE, large/small clears. Dropped: maintenance, campaign cap. The start is seeded (R72, R73, R78).
- UI: green/yellow/red, cancelled shown as a dashed red outline; four tables; Step, Run N/autoplay, Reset (R84–R86).
- Usage later: seeded noise, file replay (R88, R89). Two details are in open-questions.md.
- Model: no longer a CLSP. Small-bucket DLSP inside an MPC loop; greedy first, MILP to compare later (ADR 0013, About page R90).
- Docs cover v2 only; v1 docs and the v1 app live at tag `v1-yearly`. v1-only ADRs are superseded.
