## Plan

## Log
- **User decisions:**
  - Scope: deploy, store and partial editing; the rest was a stretch goal and also got done.
  - Repo: `fgsteen/production-planner`, public.
  - Editing UX: inline, spreadsheet-like tables.
  - "Reset to demo data": yes.
- **Deploy:** [.github/workflows/pages.yml](../../.github/workflows/pages.yml) runs `npm ci` and
  `npm run build`, then deploys `dist/`. Pages was enabled via the API (`build_type=workflow`).
  Live at https://fgsteen.github.io/production-planner/ and checked in the browser pane.
- **Store** ([src/store](../../src/store)):
  - `datasetReducer` is pure. Removing a machine or product also removes its capabilities;
    picking a new demand site clears the old one.
  - `parseDataset` rejects anything that isn't structurally a v1 dataset. Consistency problems
    are left to `validateDataset`, the same as for edits. Missing settings fall back to the seed
    defaults.
  - Persistence uses localStorage. The untouched seed is not stored, so "Demo data" vs "Your data"
    in the header is accurate.
- **UI** ([src/data/MasterData.tsx](../../src/data/MasterData.tsx)):
  - Five tabs: Machines, Products, Capabilities, Sites & logistics, Settings.
  - Cells keep a draft and commit on blur or Enter; Escape reverts.
  - A problems banner on the page, plus a count badge on the nav.
  - The page is in the URL hash (`#data`), so reloads keep it.
- **Technical defaults** (no ADR needed):
  - React context + `useReducer`, no state library;
  - new IDs are generated (P11, B5, A-S1) and can't be edited (no cascading renames);
  - import and reset ask for confirmation.
- **Model:** added `settings.planningYear`. The overview no longer hard-codes 2027.
- **Bug found by e2e and fixed:** `validateDataset` threw on dates like `2027-13-01`
  (`toISOString` on an invalid `Date`). The bad value was saved to localStorage, so the app would
  have crashed on every load. Fixed, and covered by a unit test. An `ErrorBoundary` now offers
  "Download saved data" and "Reset to demo data" as a general safety net.
- **Tested:**
  - unit: 32 tests (+19): reducer, nextId, JSON round trip and rejects, persistence fallbacks,
    invalid-date regression;
  - Playwright: 14 tests (+9): edit → overview → reload, Escape revert, new product flagged until
    it has a capability, reset, export → reset → import round trip, invalid import, planning year
    and truck lane → overview, invalid holiday reported, crash recovery;
  - manual check in the browser pane (dark mode). The pane stopped drawing partway through, so
    later visual checks used Playwright screenshots (light).
